# Plesk - One-line install command / Plesk - Tek Satır Kurulum Komutu

## 🇹🇷 Türkçe

Sistemi güncelleyip resmi Plesk tek satır yükleyicisini çalıştırır.

## 🇬🇧 English

Updates the system and runs the official one-line Plesk installer.

## Commands / Komutlar

```bash
yum update -y
sh <(curl https://autoinstall.plesk.com/one-click-installer || wget -O - https://autoinstall.plesk.com/one-click-installer)
```
