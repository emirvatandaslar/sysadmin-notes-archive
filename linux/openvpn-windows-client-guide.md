# OpenVPN - Windows client setup and usage guide / OpenVPN - Windows İstemci Kurulum ve Kullanım Kılavuzu

## 🇹🇷 Türkçe

1. OpenVPN Connect'i resmi sayfadan indirip kurun (varsayılan ayarlar): <https://openvpn.net/client/>
2. Size verilen `.ovpn` dosyasına çift tıklayın; profil içe aktarılır.
3. OpenVPN Connect'i açın, profili seçin ve **Connect**'e basın.
4. Bağlanınca yeşil simge görünür.

## 🇬🇧 English

1. Download and install OpenVPN Connect from the official page (default settings): <https://openvpn.net/client/>
2. Double-click the `.ovpn` file you were given; the profile is imported.
3. Open OpenVPN Connect, select the profile and press **Connect**.
4. A green icon appears when connected.
