# Mailcow - Restart SOGo after a hostname change / Mailcow - Hostname Değişince SOGo Container Yeniden Başlatma

## 🇹🇷 Türkçe

Mail sunucusu hostname'i değiştikten sonra SOGo container'ını yeniden başlatın.

## 🇬🇧 English

Restart the SOGo container after changing the mail server hostname.

## Commands / Komutlar

```bash
docker restart mailcowdockerized-sogo-mailcow-1
```
