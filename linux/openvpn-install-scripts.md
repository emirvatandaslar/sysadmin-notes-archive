# OpenVPN - Install scripts (CentOS, Ubuntu, Debian) / OpenVPN - Kurulum Scriptleri (CentOS, Ubuntu, Debian)

## 🇹🇷 Türkçe

Orijinalde iki kurulum betiği vardı (biri firma reklamı/logosu eklenmiş). İkisi de topluluk betiği Nyr/openvpn-install'ın değiştirilmiş kopyası olduğundan buraya kopyalanmadı; orijinal projeyi kullanın: <https://github.com/Nyr/openvpn-install>. Betik root, TUN cihazı ve CentOS 7+/Ubuntu/Debian gerektirir.

## 🇬🇧 English

The original had two install scripts (one with a company logo/ad added). Both are modified copies of the community Nyr/openvpn-install script, so they are not copied here; use the upstream project: <https://github.com/Nyr/openvpn-install>. It needs root, a TUN device and CentOS 7+/Ubuntu/Debian.
