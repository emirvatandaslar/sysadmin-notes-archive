# CentOS - Install and start Redis / CentOS - Redis Kurulumu ve Başlatma

## 🇹🇷 Türkçe

Redis'i kurar, başlatır ve açılışta çalışacak şekilde etkinleştirir.

## 🇬🇧 English

Installs Redis, starts it and enables it at boot.

## Commands / Komutlar

```bash
yum install redis
sudo systemctl start redis
sudo systemctl enable redis
```
