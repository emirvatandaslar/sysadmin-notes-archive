# PHP Selector - "Database could not find driver" error / PHP Selector - "Database could not find driver" Hatası

## 🇹🇷 Türkçe

PHP Selector'de `pdo_mysql` eklentisini **kapatın**, `nd_pdo_mysql` eklentisini **açın**.

## 🇬🇧 English

In PHP Selector **disable** the `pdo_mysql` extension and **enable** `nd_pdo_mysql`.
