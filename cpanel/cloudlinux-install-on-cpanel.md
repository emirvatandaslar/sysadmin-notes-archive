# CloudLinux - Convert a cPanel server / CloudLinux - cPanel Üzerine Kurulum

## 🇹🇷 Türkçe

cPanel sunucuyu CloudLinux'a çevirir. **Geçerli bir CloudLinux lisans anahtarı gerekir**; `YOUR_CLOUDLINUX_KEY` yerine kendi anahtarınızı yazın (anahtarı asla herkese açık yerde paylaşmayın).

## 🇬🇧 English

Converts a cPanel server to CloudLinux. **A valid CloudLinux license key is required**; replace `YOUR_CLOUDLINUX_KEY` with your own (never share the key publicly).

## Commands / Komutlar

```bash
wget http://repo.cloudlinux.com/cloudlinux/sources/cln/cpanel2cl
sh cpanel2cl -k YOUR_CLOUDLINUX_KEY
```
