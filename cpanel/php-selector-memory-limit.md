# PHP Selector - Memory limit change script / PHP Selector - Memory Limit Değiştirme Scripti

## 🇹🇷 Türkçe

PHP Selector memory limit değerini değiştiren üçüncü taraf bash betiği: <https://github.com/OmerAti/php-selector-memory-limit>. Eski değerleri yenisiyle değiştirir, dosya yoksa bilgi verir. `bash` ve `sed` gerekir. Çalıştırmadan önce okuyun.

## 🇬🇧 English

Third-party bash script that changes the PHP Selector memory limit: <https://github.com/OmerAti/php-selector-memory-limit>. Replaces old values with new ones and reports missing files. Needs `bash` and `sed`. Read it before running.

## Commands / Komutlar

```bash
wget https://raw.githubusercontent.com/OmerAti/php-selector-memory-limit/refs/heads/main/memory-limit.sh
chmod +x memory-limit.sh
./memory-limit.sh   # or: bash memory-limit.sh
```
